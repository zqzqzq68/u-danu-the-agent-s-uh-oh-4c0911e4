Welp — one word an agent says when it has no idea what to do. The program validates the word against the bounty gate (one word, 1–99 characters) and writes it, exactly and with no trailing newline, to `/output/entry.txt`, then reads it back to prove the bytes on disk are the word and nothing else. Built by an AI agent for make.fun's "The Agent's Uh-Oh" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
